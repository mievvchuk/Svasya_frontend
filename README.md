# Frontend 2 — Кошик, Checkout та Оформлення замовлення (Бренд "СВАСЬ")

Гілка: `feature/cart-checkout`

## Реалізований функціонал

1. **Спільний стан кошика (React Context + localStorage)**:
   - `CartContext` підтримує збереження у `localStorage` (стан не втрачається після оновлення сторінки).
   - Точна структура елемента:
     ```typescript
     {
       variantId: 5,
       productId: 1,
       name: "СВАСЬ Hoodie",
       price: 999,
       color: "forest_green",
       size: "L",
       imageUrl: "...",
       quantity: 1
     }
     ```
   - Захист від кількості менше 1 (`quantity >= 1`).
   - Підрахунок subtotal (`price * quantity`) та total (`sum(subtotal)`).

2. **Сторінка Кошика (`/cart`)**:
   - Відображення списку обраних товарів (image, name, color, size, price, quantity, subtotal).
   - Збільшення та зменшення кількості (`+` / `-`).
   - Видалення товару (`removeFromCart`).
   - Очищення кошика.
   - Підсумок замовлення з кнопкою переходу до Checkout.

3. **Сторінка Оформлення (`/checkout`)**:
   - Форма з обов'язковими полями: `customer_name`, `phone`, `email`.
   - Клієнтська валідація заповненості та коректності номеру телефону й email.
   - Перевірка, що кошик не порожній.
   - Відправка запиту на бекенд: `POST /api/orders`.
   - **Правильний мапінг**: `variantId` трансформується у `variant_id`:
     ```json
     {
       "customer_name": "Михайло",
       "phone": "+380XXXXXXXXX",
       "email": "example@gmail.com",
       "items": [
         {
           "variant_id": 5,
           "quantity": 2
         }
       ]
     }
     ```
   - Не передаються зайві поля (`price`, `status`, тощо) — бекенд самостійно визначає ціни.
   - Після успішної відповіді: очищення кошика + `localStorage` та перехід на `/order-success`.
   - Вбудована підтримка роботи в режимі офлайн / demo mock для демонстрації на хакатоні, якщо бекенд ще не запущений.

4. **Сторінка Успішного замовлення (`/order-success`)**:
   - "СВАСЬ ВЖЕ В ДОРОЗІ"
   - Номер замовлення (#id)
   - Сума замовлення
   - Статус замовлення та дата створення.

5. **Header**:
   - Логотип СВАСЬ
   - Каталог
   - Лічильник кількості товарів у кошику: `Кошик (N)`

6. **Каталог та демонстраційні сторінки**:
   - `/` — Головна сторінка бренду СВАСЬ з швидкими тестами.
   - `/products` — Каталог продукції.
   - `/products/:id` — Сторінка товару з можливістю обрати розмір, колір та додати в кошик.

## Запуск проекту

```bash
# Встановлення залежностей
npm install

# Запуск локального сервера розробки (порт 3000)
npm run dev

# Збірка проекту для продакшену
npm run build
```
